# GymBuddy Build Instructions 

This guide explains how to install and run the GymBuddy application locally.

## Requirements 

Install the following software before continuing:

- Git
- Docker Desktop
- Node.js 18 or Later
- npm
- A web browser (optional)
- VS Code is recommended
